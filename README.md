# 🎲 Random Quote Generator
<img width="1007" height="462" alt="image" src="https://github.com/user-attachments/assets/c941f25a-a6aa-43a2-90d6-b1920e6fa310" />

A simple and responsive **Random Quote Generator** built with **HTML, CSS, and JavaScript**.

This project displays a random inspirational quote each time the user clicks the **"Generate Quote"** button. It was created to practice JavaScript fundamentals, DOM manipulation, and event handling while building a clean and responsive user interface.

## 🚀 Live Demo

🔗 https://mohamed-atef0.github.io/-Random-Quotes-Generator/

## ✨ Features

* Generate a random quote with a single click
* Clean and responsive user interface
* Fast and lightweight
* Built using Vanilla JavaScript
* Beginner-friendly project

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
